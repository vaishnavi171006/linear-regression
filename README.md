# linear-regression
Machine Learning project using Linear Regression in Python

## 📌 Project Overview
This project demonstrates Linear Regression, a supervised machine learning algorithm, using Python. It predicts salary based on years of experience by identifying the relationship between the input and output variables.

## 🎯 Objective
- Understand Linear Regression.
- Analyze data using Pandas.
- Train a machine learning model.
- Predict salary based on years of experience.
- Visualize the regression line.

## 📊 Dataset
The dataset contains two columns:

- **YearsExperience:** Number of years of work experience.
- **Salary:** Corresponding salary value.

The dataset is a small sample created for learning purposes.

## ⚙️ Algorithm
Linear Regression finds the best-fit straight line between input and output variables.

**Equation:**

y = mx + c

Where:
- `y` = Predicted salary
- `x` = Years of experience
- `m` = Slope
- `c` = Intercept
